# Medios de la portada

Reemplazá los espacios visuales agregando archivos con estos nombres:

- `bikinis-carousel.webp`
- `hero-pijamas.jpg`
- `lenceria-carousel.webp`
- `collections/bikini-01.jpg`
- `collections/bikini-02.jpg`
- `collections/pijama-01.jpg`
- `collections/pijama-02.jpg`
- `collections/lenceria-01.jpg`
- `collections/lenceria-02.jpg`

Los videos cortos que acompañan las colecciones se colocan dentro de
`public/videos/home/collections/` con estos nombres:

- `bikinis.mp4`
- `pijamas.mp4`
- `lenceria.mp4`

Recomendaciones:

- Hero: 1920 × 900 px o más, JPG/WebP.
- Colecciones: proporción vertical 3:4, idealmente 1200 × 1600 px.
- Video del hero: MP4 horizontal, optimizado para web.
- Videos de colecciones: MP4 vertical 4:5, cortos, idealmente de 6 a 15 segundos.
- Todos los videos se reproducen silenciados y en loop.

## Imágenes provisorias

Las imágenes de `public/images/home/provisional/` se usan solamente como
respaldo para los destacados de Bikinis y Pijamas que todavía no tienen una
foto sincronizada. Las imágenes reales de cada producto tienen prioridad.
