# Pupas Mayorista — Frontend

Catálogo público construido con React, TypeScript, Vite y TanStack Query. Consume los filtros y productos sincronizados desde Dux por `mayorista-backend`.

## Desarrollo

1. Copiar `.env.example` a `.env`.
2. Iniciar `mayorista-backend` en `http://127.0.0.1:8000`.
3. Ejecutar `npm install` y `npm run dev`.

La variable `VITE_API_URL` permite cambiar la URL del backend.
